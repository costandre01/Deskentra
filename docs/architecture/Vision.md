# Deskentra Vision

## Mission

Deskentra is a modern Service Desk and CRM platform designed to help companies manage customer relationships, technical support and internal operations through a clean, intuitive and scalable solution.

The project is being developed to simulate the architecture, workflows and quality standards of a real enterprise software product.

---

# Objectives

The goal is not only to build a functional application, but also to demonstrate modern software engineering practices across the entire development lifecycle.

Deskentra focuses on:

- Clean Architecture
- CQRS
- Domain-Driven Design (DDD)
- SOLID Principles
- Feature-Based Architecture
- RESTful API Design
- Modern React Frontend
- Responsive Design
- Dark & Light Mode
- Documentation
- JWT Authentication
- Role-Based Authorization
- Ticket Workflow Management
- Ticket History
- File Attachments
- Customer Communication Workflow
- Automated Testing (future)
- Containerization with Docker
- CI/CD (future)
- AI-assisted features (future)

---

# Product Vision

Deskentra aims to become a complete business management platform by combining multiple modules into a single application.

Current modules

- Dashboard
- Ticket Management
- Ticket History
- Ticket Comments
- Ticket Attachments
- Companies
- Contacts
- Users
- Products
- Contracts
- Knowledge Base
- Settings
- Authentication

Current ticket workflow includes:

- Ticket assignment
- Work management
- Waiting for Customer
- Resolution
- Closure
- Reopening
- Customer replies
- Customer communication

The ticket workflow is designed to support movement between appropriate stages rather than enforcing a strictly linear process.

Future modules

- SLA Management
- Notifications
- Reporting
- Analytics
- Email Integration
- Push Notifications
- AI Assistant
- Customer Portal
- Role-Based Permissions
- Time Tracking
- Audit Logs

# Technical Vision

The platform is designed with long-term maintainability in mind.

Key principles include:

- Separation of Concerns
- Scalability
- Reusability
- Maintainability
- Testability
- Performance
- Security
- Dependency Inversion
- Clear separation between Domain, Application, Infrastructure and API layers

The backend uses:

- ASP.NET Core
- .NET 10
- Entity Framework Core
- PostgreSQL
- MediatR
- FluentValidation
- JWT Authentication

The frontend uses:

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- TanStack Query
- React Router

---

# Long-Term Goal

The objective is to build a portfolio-quality application that closely resembles the architecture, user experience and development practices of commercial SaaS products such as Jira Service Management, Zendesk and HubSpot Service Hub.

The project should demonstrate not only the ability to build features, but also the ability to design a maintainable software architecture, implement realistic business workflows and document technical decisions throughout the development lifecycle.
