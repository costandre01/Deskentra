# Deskentra User Stories

This document contains the primary user stories that define the core functionality of Deskentra.

---

# Authentication

## US-001 - User Login

As a user,

I want to log into the application,

So that I can access the system securely.

---

# Customer Access

## US-025 - Invite Customer

As an administrator,

I want to invite a customer contact to the Deskentra portal,

So that the customer can securely create an account.

---

## US-026 - Accept Customer Invitation

As a customer,

I want to accept an invitation,

So that I can create my Deskentra account securely.

---

## US-027 - Customer Access Control

As a customer,

I want to access only my company's authorized information,

So that customer data remains private and secure.

---

## US-028 - Customer Ticket Access

As a customer,

I want to view only tickets associated with my company,

So that I cannot access another company's support information.

---

## US-002 - User Logout

As a user,

I want to log out,

So that my session is terminated securely.

---

## US-003 - Manage User Profile

As a user,

I want to view and update my profile,

So that my personal information remains up to date.

---

# Dashboard

## US-004 - View Dashboard

As a technician,

I want to see a dashboard with ticket statistics,

So that I can quickly understand my workload.

---

## US-005 - View Recent Tickets

As a technician,

I want to view the most recent tickets,

So that I can prioritize my work.

---

## US-006 - View Ticket Statistics

As an administrator,

I want to view ticket statistics,

So that I can monitor team performance.

---

# Companies

## US-007 - Create Company

As an administrator,

I want to register a new company,

So that I can manage customers.

---

## US-008 - Edit Company

As an administrator,

I want to edit company information,

So that customer information remains up to date.

---

## US-009 - Search Companies

As a technician,

I want to search companies,

So that I can quickly find customer information.

---

# Contacts

## US-010 - Manage Contacts

As an administrator,

I want to create and update contacts,

So that customer communication remains organized.

---

# Products

## US-011 - Register Products

As an administrator,

I want to register products,

So that support requests can be associated with them.

---

# Contracts

## US-012 - Manage Contracts

As an administrator,

I want to assign contracts to companies,

So that support coverage is documented.

---

# Users

## US-013 - Manage Users

As an administrator,

I want to create, update and manage users,

So that access to Deskentra can be properly controlled.

---

## US-014 - Manage User Roles

As an administrator,

I want to assign roles to users,

So that users have the appropriate level of access.

---

# Tickets

## US-015 - Create Ticket

As a technician,

I want to create a ticket,

So that customer requests are tracked.

---

## US-016 - Assign Ticket

As a supervisor,

I want to assign tickets to technicians,

So that work is distributed efficiently.

---

## US-017 - Update Ticket Status

As a technician,

I want to change the ticket status,

So that the support process reflects the current progress.

---

## US-018 - Flexible Ticket Workflow

As a technician,

I want to move tickets between appropriate workflow stages,

So that the ticket status reflects the actual support process.

---

## US-019 - Wait for Customer

As a technician,

I want to mark a ticket as waiting for the customer,

So that I can indicate that additional information is required.

---

## US-020 - Resolve Ticket

As a technician,

I want to resolve a ticket,

So that completed support work can be recorded.

---

## US-021 - Close Ticket

As a technician,

I want to close resolved tickets,

So that completed work is recorded.

---

## US-022 - Reopen Ticket

As a technician,

I want to reopen a closed ticket,

So that unresolved issues can continue to be tracked.

---

## US-023 - View Ticket History

As a user,

I want to view the history of a ticket,

So that I can understand the actions and changes that occurred over time.

---

# Comments

## US-024 - Reply to Ticket

As a technician,

I want to add comments to tickets,

So that communication is recorded.

---

## US-025 - Customer Reply

As a customer,

I want to reply to an existing ticket,

So that I can provide additional information.

---

## US-026 - Send Communication to Customer

As a technician,

I want to send pending comments and attachments to the customer,

So that the customer receives the relevant information.

---

## US-027 - Automatic Ticket Update After Customer Reply

As a customer,

I want my reply to automatically update the ticket workflow,

So that I do not need to manually change the ticket status.

---

# File Attachments

## US-028 - Upload Ticket Attachment

As a technician,

I want to upload files to a ticket,

So that I can provide additional information or documentation.

---

## US-029 - View Ticket Attachments

As a user,

I want to view the files attached to a ticket,

So that I can access relevant documentation.

---

## US-030 - Download Ticket Attachment

As a user,

I want to download a ticket attachment,

So that I can access the original file.

---

## US-031 - Delete Ticket Attachment

As a technician,

I want to delete an attachment from a ticket,

So that incorrect or unnecessary files can be removed.

---

## US-033 - Create Article

---

## US-041 - AI Priority Suggestion

As a technician,

I want AI to suggest a priority,

So that important tickets receive appropriate attention.

---

## US-042 - AI Suggested Response
