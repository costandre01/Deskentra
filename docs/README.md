## About

Deskentra is a modern Service Desk and CRM platform developed as a portfolio project to simulate the architecture, workflows and quality standards of a real enterprise SaaS application.

The project demonstrates modern software engineering practices while providing a complete help desk solution for software companies.

The fictional company behind the platform is **FlowTech Solutions**, providing customer support for its ERP product **FlowERP**.
